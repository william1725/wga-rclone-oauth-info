# WGA CoS Rclone Backup

## About This Application

WGA CoS Rclone Backup is a personal-use application configuration that connects Rclone to Google Drive for secure, automated backups.

The application is intended solely for the account owner's use and is not a public backup service.

## Purpose

- Connect securely to Google Drive using OAuth 2.0.
- Store encrypted backup files created locally using Restic.
- Support scheduled backups and recovery of personal operating-system project files.

## Data Security

Backup data will be encrypted locally before being uploaded to Google Drive.

OAuth credentials and access tokens will be kept in the owner's local configuration and will not be published in this repository.

## Privacy

This application is intended for personal use only. It does not sell or distribute Google user data.

See the [Privacy Policy](privacy.html) for details.

## Terms of Use

This application is for the owner's personal backup operations only. It is not offered as a service to other users.
