Privacy Policy

Last updated: October 20, 2026

1. About the Application

WGA CoS Rclone Backup is a personal-use configuration of Rclone for connecting the owner's computer to Google Drive. It is not offered as a public service.

2. Google Account Access

The application uses Google OAuth 2.0 to request permission to access Google Drive. Rclone uses the authorized access to manage backup files in the owner's Google Drive account.

3. Use of Data

Google Drive access is used only for the owner's backup and recovery operations. The intended setup uses Restic to encrypt backup contents locally before uploading them.

4. Data Storage and Security

Backup files are stored in the owner's Google Drive account. OAuth credentials and tokens are intended to remain on the owner's local computer and are not published through this website.

5. Data Sharing

The application does not sell Google user data, use it for advertising, or intentionally disclose it to unrelated third parties. Google provides the cloud storage service.

6. Data Retention and Deletion

The owner controls backup retention and deletion. Stored backup files remain in Google Drive until removed by the owner or according to configured backup retention rules.

7. Revoking Access

The owner can revoke the application's Google account permissions through Google Account security settings. Stored backups can be deleted separately from Google Drive.

8. Contact

For questions, contact the application owner using the support email displayed on the Google OAuth consent screen.
